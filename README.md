# Jimoh Abdulwasiu Okandeji Portfolio

## Run locally

Use Node.js 20+ and run `npm install` followed by `npm run dev`.

## Publish to GitHub Pages

1. Create a public GitHub repository named `jokandeji.github.io`.
2. Add it as the `origin` remote, push the `main` branch, and open the repository's **Settings → Pages**.
3. Select **GitHub Actions** as the deployment source. The included workflow publishes the site automatically at `https://jokandeji.github.io` after each push to `main`.
